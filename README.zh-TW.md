# Vinutes

Vinutes 是 Mac 選單列上的錄音程式。開會時按一下就開始錄音。會議結束後，Vinutes 會把錄音轉成逐字稿，請你平常在用的 AI 整理成正式的會議紀錄，再發成同事可以直接修改、留言的 Google 文件。要寄給與會人員的信也會先準備好，你按下寄出才會寄。

> 目前是早期版本，只能在 Apple 晶片的 Mac 上執行。程式畫面有英文和繁體中文兩種。English: [README.md](README.md)

## 它能做什麼

- **從選單列錄音**：按一下或按 ⌃⌥R 開始，開會途中可以暫停、繼續。開線上會議時，不管戴藍牙耳機、有線耳機還是開喇叭，都會錄到對方說的話（需要 macOS 14.2 以上）。錄音時「我」和「對方」各有一條音量，看得出兩邊都有錄進來；要指定錄哪一支麥克風，在設定的「麥克風」選。
- **在你的 Mac 上轉逐字稿**：語音辨識用 Whisper 在本機執行，錄音不會上傳。開會的時候就一邊轉，每五分鐘左右轉一段，按結束錄音後大約一分鐘逐字稿就好了。中文會議如果人名多、有人離麥克風遠，可以在環境設定自檢的第 3 項按「更換」改用 Qwen3-ASR：人名和遠處的發言聽得比較準，也會標標點，要多下載約 4 GB。
- **開會時顯示即時字幕**：按浮動列上的 CC 按鈕，浮動列下方會即時顯示大家在講的話（需要 macOS 26 以上）。字幕只在你的 Mac 上產生，不會寫進逐字稿。
- **分辨講者**：依聲音分出不同的人。在「人員」分頁替每個聲音選是誰，紀錄和信裡的名字會跟著改，下一場會議 Vinutes 也會認得這個聲音。AI 正在修改紀錄時也可以選，名字會在 AI 改完後寫進紀錄。
- **用你已經在用的 AI 寫紀錄**：Claude Code、Codex 或 Antigravity 都可以。AI 只能讀寫這場會議的資料夾。
- **對照 Google 行事曆**：自動帶入會議名稱、時間、地點和與會人員。ERP 訂會議室時寫在行事曆內容欄的主持人、參與部門也會讀；同一個部門的人在人員分頁確認過一次，下次這個部門的會議就直接帶入。
- **發成 Google 文件並保持同步**：同事在文件上改的字和留言會顯示在程式裡。你在程式裡修改時，只會更新改過的段落，同事的留言會留在原本的位置。
- **越用越準**：聽錯的人名改過一次，就會存進這個專案的專案背景（沒有專案的會議存進詞彙表），下一場會議就不會再錯。
- **把附件放進會議紀錄**：按標題下方的「加入會議附件」放檔案、超連結或圖片，每個附件可以各寫一句說明。附件會存進雲端硬碟，列在紀錄最後一節「參考附件」；每份紀錄都有這一節，還沒放附件時寫「無」。
- **給 AI 參考資料**：用輸入框的 ＋ 和圖片按鈕放上來的檔案、超連結和圖片，只給 AI 參考，不會寫進紀錄。可以放 PDF、Word、Excel、PowerPoint、文字檔或網頁的超連結。
- **準備好要寄給與會人員的信**：收件人就是這場的與會人員，信箱從行事曆邀請和公司通訊錄找；要再加人打名字就能選。信裡有會議目的和三到五條重點；你改過會議紀錄，打開寄信視窗時，這兩段會照改過的紀錄重寫。信的最後一行寫著寄信的 Vinutes 版本。你按下寄出之前，信不會寄出。
- **用專案分類會議**：每場會議可以歸到一個專案，左邊清單上每場會議的標題底下會顯示資料夾圖示和專案名稱，每個專案的資料夾一個顏色。會議歸錯專案時，點會議上方的專案名稱就能換到別的專案，或新增一個專案。
- **每個專案一份專案背景**：在專案設定裡寫下這個專案有哪些人、各自負責什麼、常用的名詞和背景。AI 整理會議紀錄前會先讀專案背景，人名和誰負責什麼都會照專案背景寫。紀錄裡出現專案背景沒有的人名時，會列在待確認，你按「確認無誤」，這個人就會加進專案背景。
- **讀專案資料夾**：在專案設定選好這個專案放文件的資料夾，AI 整理紀錄時會讀資料夾裡之前的紀錄、提案和時程，用來補背景、核對人名和日期。AI 讀的是資料夾的複本，不會修改資料夾裡的檔案。
- **每份紀錄都有分數**：附件那一排最右邊的灰色數字是這份紀錄的分數，點一下會列出哪裡扣分、下次怎麼避免。寄出信件之前，分數是 AI 拿逐字稿核對的結果。寄出信件時，分數換成依你修改算的結果。
- **看每個月用了多少**：會議視窗左下角和選單列面板都有「用量統計」，可以按天或按專案看 AI 跑了幾次、用了多少 Token、呼叫幾次 Google、寄了幾封信，也看得到會議和 Vinutes 本身各佔多少硬碟。用量統計上線前錄的會議，會用當時留下的紀錄補算次數和時間，但補不到 Token 數和呼叫 Google 的次數。
- **整理會議清單**：不用再看的會議可以封存，也可以刪除。刪除後，錄音檔、逐字稿和紀錄會移到垃圾桶，Google 文件會移到雲端硬碟的垃圾桶。可以一次選好幾場，或在會議上按右鍵。

## 畫面長什麼樣

**選單列**：按螢幕上方的書法 V 圖示，就會打開這個面板。按紅色圓鈕開始錄音，錄音中再按同一個圓鈕就會結束。最近三場會議也可以從這裡打開。

![選單列圖示下方的面板：還沒錄音和錄音中](docs/screenshots/menu-panel.png)

**會議視窗**：所有會議和每一場的紀錄都在這裡。想改紀錄的話，在最下面的輸入框告訴 Claude 要改什麼。

![會議視窗裡的一場會議紀錄](docs/screenshots/meeting-window.png)

**浮動列**：錄音時，畫面上會出現浮動列，顯示錄了多久，也可以暫停、結束。按 CC 會在浮動列下方顯示即時字幕（需要 macOS 26 以上）。

![浮動列和即時字幕](docs/screenshots/floating-bar.png)

截圖是英文介面，裡面的會議都是虛構的；程式畫面也有繁體中文版。

## 支援哪些語言

**程式畫面**預設跟著 Mac 的語言：「系統設定 > 一般 > 語言與地區」排在第一位的語言是中文，畫面就顯示繁體中文，其他語言都顯示英文。選單列的「設定 > 介面語言」可以固定成 English 或繁體中文。選回「自動判斷」，畫面會再跟著 Mac 的語言。環境設定自檢清單的右上角也可以切換。

**會議語言**：Vinutes 會聽每段錄音的開頭、中間和結尾，判斷這場會議用哪一種語言。如果你的會議固定用同一種語言，可以在「設定 > 會議語言」直接選好，Vinutes 就不會再自己判斷。

**會議紀錄**：中文會議會寫成中文紀錄，英文會議寫成英文紀錄。其他語言的會議，紀錄用程式畫面的語言寫，逐字稿保留會議原本的語言。

各語言的辨識品質如下，每種語言用 24 句真人朗讀的錄音實測（2026 年 10 月）：

| | 語言 | 每 100 個字錯幾個（中日韓泰文以字計，其他語言以單字計） |
|---|---|---|
| 辨識準確 | 中文、英文、日文、韓文、西班牙文、法文、德文 | 3～7 |
| 可以用，紀錄要多核對 | 越南文、印尼文、菲律賓文 | 10～11 |
| 可以用，錯字比較多 | 泰文、粵語（當成中文會議處理） | 約 18 |

最常出錯的是人名、數字和日期。用團隊看不懂的語言開的會，寄出前先核對紀錄裡的這三樣。

## 需要準備什麼

- Apple 晶片的 Mac（M1 以後的機型）
- Xcode Command Line Tools（`xcode-select --install`）和 Python 3.10 以上
- 其中一個 AI 的帳號：Claude Pro 以上方案（Claude Code）、ChatGPT Plus 以上方案（Codex），或 Google 帳號（Antigravity）。AI 不用先裝，環境設定自檢會帶你安裝並登入。
- 要用 Google 文件、Gmail 和行事曆的話，需要一個 Google 帳號，並完成一次 Google Cloud 設定。程式會一步一步帶你做，大約 15 分鐘。

## 安裝方法

```bash
git clone https://github.com/miou1107/Vinutes ~/Vinutes
~/Vinutes/recorder/install.sh
```

第一次安裝會下載語音模型（約 1.6 GB），需要等一段時間。裝好之後，選單列會出現書法 V 圖示。打開會議視窗，照環境設定自檢清單完成一次設定。

## 在 Claude Code 和其他 AI 工具裡查會議

Vinutes 也可以當 MCP 伺服器用。安裝或更新 Vinutes 時，會自動接上你 Mac 上的 AI 工具：Claude Code、Codex、Gemini CLI、Claude 桌面版、Antigravity 和 Cursor。後面三個要重新開一次才看得到會議。之後才裝的 AI 工具，執行這一行就能接上：

```bash
~/.config/vin-meeting-minutes-zh/venv/bin/python ~/Vinutes/scripts/connect_agents.py
```

之後不管在哪個資料夾，問 Claude Code（或其他接上的工具）「上週的專案會議決定了什麼」，Claude 會自己去翻會議記錄和逐字稿，回答時附上是哪一天、哪一場會議。你請它改的時候，它也可以幫講者填名字、在「參考附件」補一段、修改紀錄裡的文字、加標籤或換專案。Google 文件會一起更新，「紀錄」分頁會寫是 Claude Code 改的。刪除會議和寄信，還是只能在 Vinutes 裡按。

## 怎麼更新

GitHub 上有新版時，會議視窗會出現更新按鈕。想馬上確認有沒有新版，可以按選單列的「設定」>「檢查更新」。也可以自己更新：

```bash
git -C ~/Vinutes pull && ~/Vinutes/recorder/install.sh
```

安裝或更新完成後，Vinutes 會從 GitHub 下載一個很小的檔案，用下載次數估算大約有幾台 Mac 在用。下載時不會送出這台 Mac 或使用者的任何資料。不想被計入的話，在終端機執行下面這一行，之後安裝和更新都不會再下載：

```bash
touch ~/.config/vin-meeting-minutes-zh/no-count
```

## 資料放在哪裡

設定、Google 登入資料、詞彙表、專案背景、錄音和用量紀錄都放在 `~/.config/vin-meeting-minutes-zh/`，跟 Vinutes 的程式分開放，所以更新或重新安裝 Vinutes 都不會改到這些資料。這個資料夾跟 [vin-meeting-minutes-zh](https://github.com/miou1107/vin-meeting-minutes-zh) skill 共用，Google 只要登入一次，兩邊都能用。

## 這個 repo 裡有什麼

| 路徑 | 內容 |
|---|---|
| `recorder/` | Mac 程式（Swift）和會議視窗（HTML、CSS、JavaScript），以及安裝用的 `install.sh` |
| `scripts/` | Python 程式：轉逐字稿、分辨講者、寫紀錄、同步 Google 文件、Gmail 和行事曆、環境設定自檢 |
| `SKILL.md`、`references/` | 會議紀錄的寫法：`SKILL.md` 管中文紀錄（台灣用語），`references/minutes-guide-en.md` 管英文紀錄；每場會議 AI 會讀對應的那一份 |
| `tests/` | `python3 -m unittest discover -s tests` |

## 手上只有逐字稿？

如果不需要錄音，只想讓 AI 把逐字稿整理成會議紀錄，改用 [vin-meeting-minutes-zh](https://github.com/miou1107/vin-meeting-minutes-zh) skill。
