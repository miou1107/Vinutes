# Qwen3-ASR for Chinese meetings — plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** A Chinese meeting is transcribed by Qwen3-ASR when the user chose it in the setup checklist and its model
is downloaded; Whisper stays the default, is used for every other language, and is the fallback. Nothing else
about the transcript, the pieces during the recording, the speakers or the minutes changes.

**Spec:** issue #32 (Vin 2026-10-20: 「OK就這樣吧」「開工」), the bench in `docs/bench/README.md`, and the
prototype `prototypes/speech-model.html` (the setup checklist's item 3: choose, download with progress, speed
test; a recording started before the download is done says it used Whisper).

**Architecture:**

- `transcribe.py`: `speech_model()` reads `"speech_model"` from settings.json (`MINUTES_SPEECH_MODEL` overrides);
  `qwen_ready()` checks the mlx-qwen3-asr package and the two model folders in the Hugging Face cache (the model
  and Qwen's aligner); `recogniser(lang, whisper)` returns `(name, run)`: Qwen3-ASR for `zh` when chosen and ready,
  Whisper otherwise. Qwen gets the glossary hint as its `context` (the system prompt), writes punctuated text, and
  `qwen_lines()` cuts that text at sentence ends, each line taking the aligner's word times. The final run and the
  pieces helper both call `run(audio, offset)`; the transcript's JSON and every piece say which recogniser wrote them.
- `setup_check.py`: `speech` status is for the chosen model (Qwen3-ASR: both folders, about 3.8 GB), `download
  speech` fetches the chosen model, `speech_model whisper|qwen3-asr` records the choice. install.sh adds the
  package, not the model.
- The checklist screens (item 3's cards, the download row, the speed test, the recording notice) are a second
  step, after the prototype is approved.
